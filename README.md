## ✨ Features

- **Local & Private:** All notes and images are stored locally in `~/.kizen/`. Zero telemetry.
- **Rich Text Editor:** Supports bold, italic, underline, strikethrough, and clickable checkboxes.
- **Images:** Drag & drop images or paste them directly from your clipboard (`Ctrl+V`).
- **Labels (Tags):** Organize notes using `#hashtags` and manage them from the sidebar.
- **Grid & List Views:** Toggle between a masonry grid layout and a compact list layout.
- **Search:** Fast, real-time search with text highlighting.
- **Backups & Export:** Download individual notes as Markdown or backup your entire database as a ZIP file.
- **Dark/Light Theme:** Automatically follows your system theme or can be set manually.
